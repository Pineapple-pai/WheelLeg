# 新旧模型退化的定位

[完整物理参数消融报告](../diagnostics/model_switch_causes/report.md)与[对照图](../diagnostics/model_switch_causes/model_switch_transients.png)。

固定旧v16策略、相同3个种子，在完整新模型上±2m/s起步0/3跑满；仅把轮轴armature从0.01恢复0.0001、保留新版其余物理，两方向均3/3跑满24秒。单独恢复云台COM/惯量仍两方向0/3。75回合固定策略对照支持轮轴附加惯量是此次迁移起步失稳的主要因素，不能把它当作无物理影响的平滑参数。

跑满不等于速度精度通过，旧值也未证明是硬件真值。默认模型、训练控制器和权重未变；诊断XML仅保存在`diagnostics/model_switch_causes/variants/`，未自动应用。后续应优先核实电机反射惯量及单位，固定有依据的物理版本后再训练，而不是继续在未校核的0.01上堆轮次。

旧v16继承了v15，而新版首轮6000轮从随机初始化开始，学习率也不同，训练历史不等价。物理消融定位了迁移失败的重要因素，尚未证明新版从头训练失败只有这一个原因。
