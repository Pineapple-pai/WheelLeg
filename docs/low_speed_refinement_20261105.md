# 新版模型的低速起步优化

新版模型6000轮已能在固定0.27m高度站立，尚未学会可靠运动。
±0.25m/s能存活，但速度明显不足；±0.5m/s及更高速度起步失稳。
详见[完整训练分析](../diagnostics/new_model_training_effect/report.md)和
[采样对照](../diagnostics/ppo_launch_sampling/report.md)。

已有100轮采样对照覆盖original、low_band、launch_focus及三个配对种子。
low_band保留全部站立评估，但+0.5只在一个训练种子上保持姿态，所有非零任务仍未通过5%精度。
launch_focus出现站立退化，暂不采用。

新增学习率对照使用同一6000轮Actor/Critic/Adam/归一化和探索尺度，
三个配对种子71/72/73，low_band采样、固定学习率3e-5，每次300轮×4环境×256步。
100轮保存点与已有low_band、1e-4、100轮比较；300轮结果另列，避免把训练时长和学习率效果混为一谈。
物理、奖励和低层电机参数未改变。结果见
[本次短训报告](../diagnostics/ppo_low_band_refinement/report.md)。

三种子短测已完成，新增90回合评估。3e-5在100轮未整体改善，300轮的+0.25姿态通过还从9/9降至3/9；
所有非零任务综合通过仍为0。故不采用这些新权重，后续入口保留原1e-4学习率和原6000轮起点。
low_band、1e-4、300轮是待验收候选，该组合的300轮效果尚未验证，不代表已取得稳定改进。

## 后续训练入口

`scripts/train_joint_low_speed.sh`从原6000轮权重继承，以新版本名保存，
保留探索标准差和归一化，每100轮存档，300轮后自动评估100/200/300三个保存点。
默认训练种子74，评估使用新的64010–64014，任务为站立、±0.25、±0.5m/s。
这是有限轮数的训练与验收入口，不表示已经得到合格策略。

```bash
bash scripts/train_joint_low_speed.sh
```

如需明确指定输出名与种子：

```bash
VERSION=joint_low_speed_s74_next SEED=74 bash scripts/train_joint_low_speed.sh
```

如目录已存在脚本会拒绝覆盖。可通过`TRAIN_CONDA_ENV`选择Conda环境，
`SOURCE`选择经契约检查的新版检查点前缀，`LEARNING_RATE`显式覆盖学习率。
默认仍从原6000轮检查点继承，不自动挑选短测中的幸运种子。

low_band仅压缩非零vx命令至绝对值0.25–0.5；零速、高度、yaw、移动起步概率0.35及初始速度范围0.4–2m/s、推力和域随机化仍保持原分布。
因此它不是完全隔离的低速初态课程。验收为0.27m、无推力/无移动初态的名义参数测试，不能替代训练原分布或实机鲁棒性验收。

升速要求沿用冻结门槛：四个低速起步任务分别在三个评估种子上综合通过，
至少两个训练种子成立，且所有训练种子站立保持通过。未过门槛时不自动扩展至±1/±2m/s。
下一步若学习率和采样仍不足，应单独比较初始速度分布或速度奖励取舍，避免同时调整模型、奖励和电机映射。
