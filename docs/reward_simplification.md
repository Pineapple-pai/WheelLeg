# 奖励简化与受控对照设计 v1

2026-11-04。实现与运行检查已完成，正式训练尚未启动。该实验用于检验设计，
不预先认定简化一定更优，也不以奖励总分跨组排名。

## 目标和范围

将v15的43个奖励分项收敛为4个明确分组，另设1项可选同轴成本。
这4组包含7种标量状态误差、1种动作变化正则和一次性失败成本；
并非将原43项改名打包。删除腿长相等、腿落差、腿部差分速度、左右关节目标相等、
连杆前后伸出、每腿轮位居中、重复速度/高度/姿态项、多个输出平滑项和饱和奖励。
上述量仍可记录和用于验收。保留硬执行器限幅与原失败终止条件。

完整奖励在`uz05/simple_rewards.py`独立定义；环境在入口提前返回，
不会执行旧奖励或旧的几何质量乘法门控。继承v15的旧阶段布尔标志只用于保持
采样、物理、观测、终止和诊断兼容，不能解释为旧奖励仍有效。

## 确切定义

定义`ρ(x)=x²`（|x|≤1），否则`ρ(x)=2|x|−1`。
连续项为每秒奖励率，乘控制周期dt=0.008后累加；终止成本只扣一次。
归一化尺度与系数在四组中固定相同，未加入训练进度退火或课程。

| 分组 | 每秒奖励率／事件成本 |
|---|---|
| `task_tracking` | `3 − ρ(ev/0.30) − 0.5ρ(eω/0.50) − ρ(eh/0.025) − 0.5ρ(dstop/0.10)` |
| `body_attitude` | `1 − 0.5ρ(roll/5°) − 0.5ρ(epitch/7°) − 0.3ρ(eheading/5°)` |
| `action_smoothness` | `−0.05 mean((Δaction/0.10)²)` |
| `failure` | 环境真实terminated时扣5；正常time limit不扣 |
| 可选`axle_alignment` | `−ρ(max(0, daxis−0.002)/0.010)` |

速度单位m/s、yaw rate为rad/s、高度/位移为m。
`dstop`仅零速度且零转速命令时启用，锚点在进入停车时捕获一次；运动时该误差为零。
该位置要求属于站立任务定义，独立于速度误差，不会压低或乘掉其他跟踪信号。
它仍可能与快速制动竞争，停车位移必须单独验收，不能预先认为问题已解决。

`eheading`仅站立或直行时启用，使用既有停车锚点/直行进入航向。
主动转向时此误差为零，使用yaw rate命令跟踪；不要求yaw始终为世界零度。
关节动作变化按最短周期角差换算到归一化动作单位，跨±π不产生伪跳变；
轮速动作按普通差值计算。只保留这一种输出正则。
没有腿长或关节角相等的奖励，也不强制两轮或四关节共用动作。

## 姿态参考与2×2对照

| 实验臂 | stage | pitch参考 | 同轴成本 |
|---|---|---|---|
| `legacy` | `joint_tracking_v15` | v15原奖励 | v15原奖励，无新增直接轴线项 |
| `minimal` | `joint_tracking_simple` | 车身零pitch | 关闭 |
| `minimal_axle` | `joint_tracking_simple_axle` | 车身零pitch | 开启 |
| `support` | `joint_tracking_simple_support` | 车身与整机支撑倾角对齐 | 关闭 |
| `support_axle` | `joint_tracking_simple_support_axle` | 车身与整机支撑倾角对齐 | 开启 |

支撑参考是两轮心中点降低一个轮半径；支撑倾角为该参考到整机质心的向量，
在水平航向与世界竖直方向组成的平面内的倾角。
`support`使用车身上方向与该向量的周期角差作为`epitch`。
这是随状态变化的几何参考，不是经完整动力学验证的轨迹，也不保证它会给出期望姿态。
因此将它作为一个独立因素验证，而非直接认定优于零pitch。

本次不生成加速度或跳跃参考轨迹，不将速度命令按正负转换为pitch，
不平滑原始命令，不修改动作或加入教师、平衡外环。
若后续引入时间轨迹，需要另外验证可行性，并保证策略能观测参考状态或相位；
本次四个实验臂的观测接口保持一致。

主要因果比较：minimal_axle↔minimal、support_axle↔support检验同轴项；
support↔minimal、support_axle↔minimal_axle检验pitch参考；同时检查因素交互。
legacy与简化组的比较是整套设计比较：其权重、项结构及连续奖励计时单位均变化，
不能把结果归因于单一项的删除，更不能直接比较训练reward。

## 控制变量与预算

- 四组采样全部从v15复制，包含同一±2m/s速度带、0.22–0.32m高度、
  停车/换向概率、命令保持时间、35%运动初态、域随机化及扰动。
- 每组默认从同一v15最终checkpoint开始，保留探索标准差，每组都重置VecNormalize。
  观测/动作、执行器、MJCF、网络、固定学习率3e−5、8环境、512步rollout、
  512 batch、4000次更新及PPO设置一致。
- 训练种子0/1/2，5臂共15次训练；按种子配对，顺序运行，避免多组同时占用训练资源。
  相同动作下物理、观测、终止和命令采样回归检查通过。
- 这是“同一起点续训”的比较，继承了旧策略/critic偏好，不能代表从零学习效率。
  `--from-scratch`可建立另一批独立实验，全组改为同种子从零初始化；结果不可混入续训批。

原轮位硬终止仍保留：这不是“完全没有几何约束”的实验。
它限制所有组相同的可行域，以免同时改变奖励与终止条件。
若简化组大量触发轮位终止，应如实记录，不能先放宽边界使其看上去更好。

## 计划与运行入口

```bash
# 仅生成/核对计划，不训练；可用宿主python3执行。
python3 scripts/compare_simple_rewards.py

# 真正执行已核对的15次正式训练及后续评估；本轮没有执行此命令。
python3 scripts/compare_simple_rewards.py --execute
```

默认计划为`logs/reward_simplification_v1/manifest.json`，保存各组配置、全部命令、
共同checkpoint及主要源码SHA256。再次执行时计划必须匹配，拒绝覆盖已有模型目录。
每组训练和评估各自写日志；成功结束训练后才执行评估，失败会中止后续任务。
需要独立批次时指定新的`--name`，并可选`--arms`、`--seeds`。
默认训练脚本及旧模型阶段没有切换为未经验证的简化组；这些组通过本入口显式选择。

```bash
# 单独检查四个简化臂的训练→保存→评估流程，仅各2次小更新。

  --arms minimal minimal_axle support support_axle --seeds 0 \

# 固定v15策略，在同一条物理轨迹上重算四组奖励，不训练新策略。

  checkpoints/joint_tracking_pos_v15/checkpoint \

```

## 统一验收与选型

正式入口为每次训练自动运行：

1. 名义动力学、无外推、保留观测噪声：reverse10、反向起步、双向stop_go10、
   motion、双向高速调高度、turn，各5个未参与训练的种子30000–30004。
2. 同一套协议开启域随机化和推力扰动，使用相同种子。
3. 固定命令24s：高度0.22/0.27/0.32m、速度幅值1和2m/s，
   stand/forward/reverse/yaw_left/yaw_right，每种情况5个种子。

先看存活和终止原因，再看速度误差、过零、T90、±0.05m/s稳定时间、
停车漂移、车身姿态、实际轴线偏移和摆腿幅度/持续时间。
所有几何量在不含对应奖励的实验臂也同样记录。
固定命令报告新增真实轴线偏移峰值及排除首秒后的均值/P95；“排除首秒”不代表已经稳定。

`summary.json`逐训练种子保存完成回合数、计划/观测到的片段数、
成功获得T90的反向片段数和条件均值。未达到的响应保留null，未到达片段不算成功。
提前失败的回合只观察到部分轨迹，不能凭较低的观测误差优先选择；
必须回看每种协议的原始JSON，不以汇总条件均值代替成功率。

选型顺序预先固定：
- 存活较差的组不能靠较小姿态误差获胜。
- 在完成相同协议的前提下，比较速度、停车、车身姿态和摆腿；必须覆盖三个训练种子。
- 若关闭同轴成本已经达到所需轮轴精度，保留更简单的无同轴方案。
- 若开启同轴项能稳定减少错轴，需同时确认没有明确损害生存、换向和转向能力。
- 本轮尚未给工程验收误差阈值下结论，不凭3个训练种子宣称统计显著或普适最优。

## 本轮验证结果

101项测试通过，包括旧奖励入口隔离、4/5组项边界、大误差梯度、正反对称、
连续项dt积分与终止脉冲分离、周期动作、停车/转向定义、相同物理及相同采样。
四个简化臂完成小规模续训和一次reverse10评估，写出checkpoint/契约/归一化量。
后续核对发现这次旧检查请求2×64步，但load恢复了源模型512步配置，
实际每臂采样1024步并做1次PPO更新；此前的“2次更新”描述不准确。
结果在`logs/reward_simplification_v1_smoke/`，它们只是流程检查，不用于比较策略质量。
固定命令报告的轴线指标读写及简化奖励日志也已单独运行验证；计划重复读取检查通过，
`git diff --check`通过。

冻结v15策略的重计分审计，非实验因素奖励率最大差异为0。
reverse10上四组task_tracking均值都为2.477/s、action_smoothness约−0.001/s；
只改变pitch参考时body_attitude从0.835/s变为0.637/s；
开启同轴项额外约−1.515/s，原task_tracking不变。
这些数字只说明成本在相同轨迹上的作用，不证明新策略训练效果。
motion轨迹仍在1409步触发原轮位终止，未被奖励重计分掩盖。

正式15次训练未启动，当前没有“简化奖励已经优于v15/v16”的结论。
