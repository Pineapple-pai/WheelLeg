# v5：行驶俯仰偏置与站立轮速抖动诊断

本次只诊断已有最终 v5 checkpoint，不修改策略、噪声配置或训练奖励。
两类问题分别存在：行驶时是持续的俯仰姿态偏置，站立时是带噪观测驱动的轮腿输出抖动。
上一轮只看机身姿态、双轮接地和平均饱和，并不足以证明轮腿的高频输出已平滑。

## 复现条件

最终第 6000 轮，名义动力学，无随机外推力；确定性 PPO，种子 20000，高度 0.27m。
站立、前进 +0.3m/s、倒退 −0.3m/s，各记录 12 秒，统计排除首秒。
关闭噪声时保持相同初态与固定命令；改变的是观测噪声，而不是动作是否随机采样。
冻结状态试验保留随机数发生器状态，不改变后续轨迹的随机序列。

| 命令 | 观测噪声 | pitch 均值 | pitch 标准差 | 实际 vx 均值(m/s) |
|---|---|---:|---:|---:|
| 站立 | 开 | +0.37° | 0.92° | −0.0002 |
| 站立 | 关 | +0.01° | 0.54° | −0.0009 |
| 前进 | 开 | −12.15° | 0.57° | +0.135 |
| 前进 | 关 | −11.15° | 0.20° | +0.149 |
| 倒退 | 开 | +10.05° | 1.27° | −0.219 |
| 倒退 | 关 | +10.24° | 0.83° | −0.221 |

关闭噪声并没有消除行驶大倾角。这里的倾斜维持数秒，不能只解释为加速瞬间需要倾身。
前进还持续欠速，不能称为已经学会正确的稳态行驶姿态。

## 为什么奖励允许这种姿态

当前直立收益为 `3 * exp(-(roll² + pitch²) / 0.12)`。
忽略 roll，10° 时仍能得到约 2.33/3，12° 约 2.08/3；该项不是小角度直立的严格要求。
几何目标只限制轮心相对髋部的错位范围，没有约束移动时持续的 pitch 偏置。
`angular_velocity_xy` 约束角速度，稳定倾斜时角速度小，也不会因此产生大代价。

因此当前策略有空间用倾斜车身配合腿部构型维持运动，换取其他任务收益。
这是奖励结构支持的解释；没有进行重训练消融，不能断言它是唯一原因。
下一版需要单独验收并约束稳态俯仰偏置，同时保留起停和受扰恢复的倾身空间。
仅提高角速度惩罚不能纠正静态倾斜。

## 站立高频输出的直接证据

| 指标 | 原观测噪声 | 关闭观测噪声 |
|---|---:|---:|
| 轮速目标相邻帧变化 RMS | 0.745rad/s | 0.00437rad/s |
| 四关节位置目标相邻帧变化 RMS | 0.05415rad（约 3.10°） | 0.000156rad（约 0.0089°） |
| 实际轮速波动的 >10Hz 功率比例，左/右 | 79.9% / 84.3% | 0.038% / 0.027% |

实际轮速按每个 2ms 物理步记录，频谱采样率为 500Hz，不用 125Hz 策略采样推断高于其奈奎斯特频率的振动。
频谱功率比例分母采用 ≥0.5Hz 的波动功率，排除直流。
俯仰的高频功率很小，而实际轮速高频分量很大，与用户观察一致。

这也说明，不能把腿抖全部归因于轮子：四路关节位置目标本身就在跳变。
轮驱动通过底盘和支撑机构传递的扰动，与关节自身变化的目标共同作用。
机身俯仰变化较小不代表驱动输出平滑。
关闭噪声后振动大幅下降，不支持将本次现象主要归因于底层速度环自行振荡；
底层环路和接触动力学仍会影响输出到实际轮速的响应。

## 哪些观测在触发输出

冻结同一个站立物理状态与上一帧动作，仅改变某一观测块的噪声，各采样 512 次。
无需机器人移动，就能让确定性策略产生不同输出。

| 单独变化的噪声块 | 左/右轮速目标标准差(rad/s) |
|---|---:|
| 地形预览 | 0.573 / 0.282 |
| 机身角速度 | 0.310 / 0.189 |
| 重力投影 | 0.212 / 0.209 |
| 线速度 | 0.191 / 0.056 |
| 关节速度 | 0.089 / 0.112 |
| 高度测量 | 0.132 / 0.040 |

这是单个状态的局部敏感性，不是各通道对全轨迹的可加贡献。
当前地形预览噪声相当于每个 8ms 策略帧注入独立 ±5cm 的高度扰动，平坦地面也如此；
高度测量噪声同样为 ±5cm，关节/轮速度噪声为 ±0.75rad/s。
actor 是单帧 MLP，没有历史观测；确定性执行只关闭动作分布采样，不关闭输入噪声。
此次局部试验中，平地上不必要的地形预览变化对轮输出的影响最大。

当前站立的轮速目标变化代价只有约 `0.04*(0.745/2)^2 ≈ 0.0056/步` 的量级，
相对每步数个单位的任务收益很小；因此“有平滑奖励”不等于已学会抑制高频变化。
该近似忽略 robust-square 在大变化处的线性分段，仅用于量级解释。

## 修订方向

1. 先按本任务和实际传感器带宽标定观测噪声，处理平地预览每帧出现虚假高度变化的问题。
   关闭全部噪声只用于定位，不能作为已解决鲁棒性的结论。
2. 固定加入稳态 pitch 质量要求，同时保留动态起停、外推力下的恢复动作空间。
3. 同时考核轮目标变化、实际轮速/输出的高频分量、关节位置目标变化与实际关节速度。
   不能只用平均饱和、双轮接地或低 pitch 波动替代。
4. 奖励量级与任务得分一起校验，避免重新出现正则过强、恢复动作被压制的问题。

以上可以在观测与固定 PPO 目标内实现，仍使用两轮速度、四关节周期位置六维动作。
本次没有给现有 checkpoint 添加滤波、冻结动作或修改驱动增益。
