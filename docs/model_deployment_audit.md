## 原始 CAD 可用性

`/home/p/下载/UZ-05-open总装` 包含约 `477 MB` 数据：25 个 SolidWorks 装配体、170 个零件和 9 个 STEP 文件。文件不为空，主文件大小和时间戳合理，因此不是仅有网格的导出包，比 `11.57` URDF 包更适合作为模型重建来源。

优先使用：

| 文件 | 用途 | 当前判断 |
| --- | --- | --- |
| `串联腿装配方案2.SLDASM` | 恢复腿部闭链、铰点和装配支路 | 最关键，必须在 SolidWorks 中检查 mates |
| `底盘总装.SLDASM` | 获取底盘、左右腿和轮子的安装关系 | 应作为训练机器人主体来源 |
| `UZ-05-open总装.SLDASM` | 核对完整实物构型和总质量 | 包含云台/发射等无关机构，不应整体导入训练 |
| `2_交腿轮.SLDPRT`、`2_轮包胶.SLDPRT` | 获取轮胎几何和半径 | 可用于建立简化圆柱碰撞体 |
| `平衡总装.SLDPRT` | 展平几何或质量参考 | 不能替代装配体，通常不保留 mates 和关节语义 |
| 电机与减速器零件/装配 | 外形、安装位置和 CAD 质量参考 | 不能替代厂家力矩、转速、电流和热参数 |

当前 Linux 环境没有 SolidWorks 或可读取 SolidWorks mates 的 CAD 工具，而且这些新版本二进制文件不能由 `file`、`strings` 或 ExifTool 解析。因此目前无法在本机确认主装配引用是否全部解析、是否存在 suppressed/virtual components、mate 类型和配置名称。FreeCAD/Assimp 即使能读取导出的 STEP，也不会可靠保留 SolidWorks mates。

这些 CAD **可以使用，但必须先在 Windows SolidWorks 中完成一次受控导出**：

1. 用与文件版本兼容的 SolidWorks 打开 `串联腿装配方案2.SLDASM`，执行 `File -> Pack and Go`，包含所有引用、虚拟零件和 Toolbox 零件；缺失引用必须清零。
2. 记录使用的 configuration、所有 suppressed components、柔性子装配设置和 mate 错误；腿装配必须能在目标全行程内求解。
3. 从 `底盘总装.SLDASM` 建立只含底盘、两条腿、两轮和实际控制器/电池质量的训练配置，移除云台、发射和装甲等无关运动机构，但保留其真实等效质量和惯量。
4. 导出该配置的 STEP AP242 作为几何基准，同时保存 SolidWorks 质量属性报告和关节/铰点坐标表。STEP 只用于几何核对，不作为关节定义来源。
5. 单独导出左右腿的输入轴、闭链铰点和机械限位。URDF 仍需按独立广义坐标重新建模；闭环约束在 Isaac USD 中显式建立并验证残差。
6. 为每个主动电机另建执行器参数表，不能从 CAD 文件名推断减速比或力矩曲线。

完成以上导出后，这批文件足以开始重建可信的训练模型；在此之前，只能用于证明“原始装配数据可能存在”，不能直接解除跳跃和实物部署阻塞。

项目中已经准备了后续入口：

- `tools/solidworks/export_uz05_leg.bas`：在 Windows SolidWorks 中提取组件、变换、质量数组和 mates。
- `tools/solidworks/README.md`：受控导出步骤和交付目录。
- `cfg/model/uz05_deployment.template.yaml`：每侧关节、电机、接触、控制和安全参数模板。
- `scripts/validate_uz05_deployment_data.py`：缺少实测值或违反基本安全约束时返回失败。

这些文件没有接入当前 Hydra 训练配置，不影响 `v6`；只有 CAD 提取和实物参数校验通过后，才创建新的 deployment USD 和训练任务。

## 已确认问题

### URDF

- 总质量为 `13.710644 kg`，其中机身和云台约 `10.962479 kg`。
- 17 个非固定关节全部缺少 effort、velocity、机械限位、damping 和 friction。
- 没有 transmission、减速比、执行器或控制器描述。
- `Lcrank` 是 continuous 且质量 `0.271215 kg`，`Rcrank` 却是 fixed 且质量 `0.109163 kg`。
- 轮子支撑链只有：
  - `base_link -> LL -> Lcal -> Lwhl`
  - `base_link -> RL -> Rcal -> Rwhl`
- 其余连杆被导出为开树枝。真实多连杆腿是闭链，但 URDF 中没有闭环约束，因此关节运动和受力路径错误。
- SolidWorks 导出日志重复报告 `Link.Joint.ChildLink.link` 列未写入。

### USD

- USD 继承了 URDF 的开树结构；把 `Rcrank` 改为 revolute 也不能恢复闭链。
- 导入的角驱动 stiffness 为 `1e7`、damping 为 `0`、max force 为浮点最大值，不是执行器模型。运行时代码虽会覆盖部分值，但仍不具备部署含义。
- 非轮关节约 `[-1.57, 1.57] rad` 的限位是后加的通用值，不是机械硬限位。
- 左轮中心约 `X=-0.2273 m`，右轮中心约 `X=+0.2023 m`，几何不对称。`balanced.usd` 的镜像修补没有实物测量依据，不能用于部署标定。
- 当前训练 USD 每个链接使用完整网格的单个 convex hull；`base_link` 的单凸包会填充凹腔。
- 轮胎碰撞网格没有显式 PhysicsMaterial。地面摩擦配置不能代替轮胎橡胶参数及组合规则标定。
- 轮子 STL 半径约 `0.06 m`、宽度约 `0.0293 m`。

2026-08-24 的运行诊断显示：

- `v6` 稳定后两轮约 `0.96 rad/s`，无滑移理论车速约 `-0.058 m/s`，实际车速约 `0.001 m/s`，瞬时滑移比约 `100%`。
- 开环恒定 `0.25` 动作可以产生约 `-0.24 m/s` 车速，说明轮轴方向和高速驱动链路并非完全失效。
- 因此问题主要出现在低速接触/摩擦/驱动力区间，不能用“画面中看不出轮子转动”判断。平移训练前必须用多档恒定轮速扫描，拟合低速死区和滑移曲线。

### 直立接地

零姿态下碰撞体最低点：

- 左轮：`Z=-0.08917 m`
- 右轮：`Z=-0.08909 m`
- 左右小腿 `Lcal/Rcal`：`Z=-0.06160 m`
- `base_link`：`Z=-0.03500 m`

按当前重置高度 `0.084 m`，轮子初始压入地面约 `5 mm`，小腿仍离地约 `22 mm`，底盘离地约 `49 mm`。因此直立零姿态下主要支撑确实来自轮子，但 `5 mm` 初始穿透偏大，后续应根据真实轮胎变形和 PhysX contact/rest offset 标定，而不是只靠奖励适应。

## 为什么现在不能做跳跃

以整机 `13.7 kg`、跳高 `0.1 m` 粗估，起跳速度约 `1.4 m/s`。若有效伸腿行程为 `0.15 m`，忽略损耗时平均总地面力也约为 `224 N`，每侧约 `112 N`。真正所需电机力矩取决于闭链雅可比、减速比和瞬时姿态；当前模型缺少这些信息，无法计算，也无法保证仿真动作不会损坏实物。

## 必须补齐的实物数据

1. 左右腿独立电机数量、名称，以及电机到每个闭链输入轴的映射。
2. CAD 装配体或闭环几何约束：杆长、铰点坐标、装配支路和奇异位形。
3. 编码器零位、正方向、分辨率、机械硬限位和软件安全限位。
4. 每个减速器速比、效率、回差，以及电机连续/峰值力矩和转速曲线。
5. 驱动器电流、母线电压、温度降额和持续时间限制。
6. 实机控制频率、通信与观测延迟、动作滤波和失联制动行为。
7. IMU 安装坐标、轴方向、零偏/噪声，以及机身质心和惯量实测或可信 CAD 值。
8. 轮胎半径、宽度、胎压/硬度及地面上的纵向和横向摩擦测试。

仅凭零件名 `MT2042`、`RA6008`、`3508` 不能推出上述参数。

## 推荐实施顺序

1. 保留 `v6` 和 `twowheel_uz05.all_joints.usd`，只作为固定腿站立基线。
2. 获取原始 SolidWorks 装配文件或重新建立闭链模型，明确真实主动关节；先做运动学扫描，确认全行程无断链、穿模和错误支路。
3. 建立独立的 `deployment` USD/配置，写入实测质量、惯量、限位和执行器饱和，不把经验参数混入基线。
4. 先验收轮式平移：轮缘理论速度与车速一致、只有轮胎接地、正反方向和左右轮符号正确。
5. 再加入腿关节做静态高度控制和缓慢蹲起，随后做扰动站立与平移联合训练。
6. 最后才加入低高度跳跃课程，并在仿真和实物两侧限制关节位置、速度、力矩、功率、温度和落地冲量。
7. 实物首测必须吊装或带保护架，从只读观测、零力矩、低力矩站立逐级放开，禁止直接运行仿真全幅策略。

## 验收门槛

- 运动学：闭链位置残差小于 `0.5 mm`，左右全行程无支路跳变。
- 接触：静止时仅两轮有持续地面法向力，非轮碰撞体无支撑力。
- 平移：稳态低速下 `abs(R * mean(wheel_rate) - body_speed)` 小于目标速度的 `10%`；加减速段单独统计。
- 执行器：仿真命令始终受真实位置、速度、力矩、电流和热限制约束。
- Sim-to-real：质量、质心、惯量、摩擦、延迟和电机强度全部做参数随机化，但随机范围来自测量误差而非猜测。
- 跳跃：仿真峰值力矩、电流和落地冲量均低于实物安全限制，并通过低高度逐级验证。
