```bash
cd /home/p/下载/WheelLeg

VERSION="joint_transfer_armature001_$(date +%Y%m%d_%H%M%S)" \

```

这是下一段有保护的训练命令，不是已验证全任务收敛的长训配方。`SOURCE`已经是当前0.001模型的新初始化文件；不要直接换成原始旧XML权重，也不要续训本轮倒地的随机初始化权重。

固定设置：`joint_tracking_startup_precision`，`startup_balanced`，8环境×256步/轮、batch256、50轮共102400个新转移；CPU/subproc，固定lr3e-5、entropy0.001。初始6维std0.02，后续由PPO学习；切换到precision奖励时重置奖励RMS，保留网络和Adam。已训练同阶段来源则保留std与奖励RMS。所有六维动作自由，腿未冻结，电机、惯量和动作映射不变。

命令分布：25%全程零速，六种双向速度各12.5%；每个24秒回合前3秒零速，随后保持选定命令，高度0.27m、yaw0。零速和平移都计算速度跟踪，零速另有站位和航向目标。

脚本先以66300–66302种子评估来源，再训练、再用同种子评估候选。训练日志`logs/$VERSION.log`，结果`diagnostics/$VERSION/evaluation/results.json`，进展判定`diagnostics/$VERSION/progress_gate.json`。完整日志与TensorBoard分别记录运动帧比例、到达起步的回合比例、动作饱和和姿态。

退出码3表示候选没有通过进展门槛，文件仍会保存，来源不会被覆盖。门槛要求每个已有姿态/综合成功不退化，各速度均值RMSE不能恶化超过半个速度容许带，并满足双方向误差改善且归一化误差至少下降10%，或新增非零综合成功。`fully_passed_all_tasks`单独显示是否所有任务真正通过5%速度/姿态/存活联合验收。不要把`accepted_for_further_training`理解为全面达标。
