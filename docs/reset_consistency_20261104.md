## 1. 原始 Reset 与模型映射

实际训练模型由 `scripts/uz05/spec.py:MODEL_XML` 指向仓库根目录
`uz05_修正后(3).xml`，不是 `diagnostics/uz05.xml`。
模型 SHA256 为 `22fc08a5f900ffc20d977c29851618fb0ca03c1d6b01dd2da0f32209ba505c54`；本次未修改 XML。
地面由 `model.py:_build_xml()` 注入，测试包含真实训练场景的地面和碰撞。

原始 Reset 顺序：`mj_resetData` → 设置高度/机身姿态 → 采样机身速度 →
采样四个主动关节角度及速度 → 可选滚动起步 → 域随机化 → `mj_forward` → 观测。
被动关节保持 XML 零位及零速度。`mj_forward` 计算动力学但不投影 qpos，
所以角度和速度均可能不满足闭链。

PPO 顺序保持为左轮、右轮、左 link2、左 link4、右 link2、右 link4。
v16 两轮仍为 ±48 rad/s，四腿仍为独立周期绝对位置目标（动作乘 π，取最近等效周期）。
XML motor 声明是四腿在前、两轮在后；原代码通过固定切片写 ctrl，
本次改为按 motor 名称查 ID 并验证绑定 joint，数值控制语义不变。
自动测试反转临时模型的 actuator 声明顺序后，单步 qpos/qvel 仍与原顺序一致。

四组闭链及 Site：

| Equality | Site A | Site B |
|---|---|---|
| left_close_link3_link4 | left_site_link3_to_link4 | left_site_link4_to_link3 |
| left_close_link6_link2 | left_site_link6_to_link2 | left_site_link2_to_link6 |
| right_close_link3_link4 | right_site_link3_to_link4 | right_site_link4_to_link3 |
| right_close_link6_link2 | right_site_link6_to_link2 | right_site_link2_to_link6 |

每侧两个主动关节为 chassis→link2、chassis→link4；四个被动关节为
link2→link5、link5→link3、link5→link1、link1→link6。
两个 Connect 在腿的矢状平面内提供四个标量闭合条件，求解该侧四个被动角度。
轮子自转不改变闭链连接点位置，不纳入位置求解。

## 2. 实现与开关

- `scripts/uz05/reset_projection.py`：独立位置/速度投影。所有 joint/Site/Equality
  按名称查 ID，分别使用 `jnt_qposadr`、`jnt_dofadr`。
  使用 Site 世界坐标误差及 `mj_jacSite` 的差构建 Jacobian，通过 SVD 最小二乘
  Gauss–Newton 求解；单次步长限制 0.15 rad，回溯线搜索，最多 20 次迭代。
- 位置求解只改八个被动角度，从 XML 合法零位出发。接受阈值 1e-8 m，
  不是通过放松误差阈值接受初始化。保留原始主动采样、根位姿、轮角。
- 装配检查：被动角度距零位不得超过 0.5 rad；各侧平面约束 Jacobian 的行列式
  符号必须与 XML 分支一致；轮心在髋轴下方 0.15–0.34 m、前后偏移不超过 0.10 m。
  这些是当前 ±0.05 rad 初始化附近的局部装配检查，不是全工作空间 IK。
- 速度求解只改八个被动速度，解 `Jp Δvp = -Jv`，保留机身、主动关节和轮速；
  验证各连接点相对速度不超过 1e-8 m/s。
- `env.py:reset()`：域随机化之后、初始观测之前调用投影，最新 robust 阶段还拒绝
  超过 1e-5 m 的初始接触穿透。拒绝后重采样主动角度和速度，最多 8 次，失败明确报错。
  每次拒绝原因、次数、迭代数可从 `env.reset_projection_info` 查看。
  旧低高度阶段保留原有地面放置条件，不通过抬高机身修改其配置。
- `spec.py:RobotParams.closed_chain_reset=True` 默认启用；设为 False 完整保留旧初始化。
  `reset_projection_attempts=8` 控制最大尝试次数。
- `train_uz05.py` 增加 `--legacy-reset`，用于旧 Reset A/B；默认启用投影。
  开关写入 training_config、最终及中间 checkpoint contract。
- `model.py` 缓存求解器索引及执行器名称映射，不在 Reset 重新加载模型。

原始质量、惯量、碰撞、Equality、重力、执行器参数、奖励、PPO 网络和超参数均未修改。
未做固定关节、关闭约束或额外稳定控制。

## 4. 起步瞬态对照

100 个配对种子，两组分别仿真 0.5 s，同时统计前 0.1 s。
控制一：直接零电机力矩；控制二：固定 PPO 输入
`[0.1, 0.1, 0.01, -0.01, 0.01, -0.01]`，通过现有执行器每物理步计算控制。
未使用 PPO 策略，也未添加推力；保留重力、接触、域随机化和原始初始滚动速度。
这是控制相同的对照，非“站立成功率”测试。

两组使用投影组接受的同一根位姿、主动角度、主动速度和轮状态；
旧组被动位置/速度恢复零位。这样只比较被动初始化差异。
对于 4 个接触拒绝种子，旧组也采用接受后的主动采样，避免重采样混淆；
因此瞬态旧组初始误差中位数是 4.082 mm，与未筛选 Reset 的 4.232 mm 略有不同。

修复组 0.1 s 峰值中位数约 0.065/0.058 mm；零力矩 0.5 s 约 0.172 mm。
不能把初始化精度误解为后续每一步都强制达到 1e-8 m。
