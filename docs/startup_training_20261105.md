# 新版模型起步诊断与重新训练

诊断报告：[命令/轮速/腿部动作配对消融](../diagnostics/launch_cause_ablation/report.md)。

固定权重下，速度命令缓升、轮速目标限速、保持起步前腿部目标均未恢复可靠的±0.5m/s起步。
因此不把轮速限幅或冻结腿部作为正式修复，也不据此盲目提高smooth惩罚。
这些试验不能唯一定位网络内部责任，但不支持把失败简单归因为命令阶跃、轮目标变化率或腿部大动作中的单一因素。

基础阶段为`joint_tracking_startup`。当前默认用新版6000轮站立检查点初始化，先做有限短训。
此前从头训练到1000轮，平均回合仍约0.8秒，独立站立评估也失败；因此改为保留已有站立能力。
本次结果见[预训练初始化短训报告](../diagnostics/startup_warmstart/report.md)。
三个种子150轮短训已完成：训练回合约2073–2570步，但非零速度综合验收仍未通过，
因此当前入口仅保留为有限短训，不建议直接延长至6000轮。

| 项目 | 配置 |
|---|---|
| 模型 | models/uz05_20261104/uz05_rl.xml |
| 权重初始化 | 新版6000轮Actor/Critic/Adam，保留归一化与六维探索标准差 |
| 动作 | 原六维：两轮速度、四个主动关节周期位置 |
| 每回合命令 | 前3秒站立，随后保持同一速度至24秒 |
| 站立回合 | 25%整回合零速 |
| 非零目标 | ±0.1、±0.25、±0.5m/s，各12.5% |
| 高度/偏航 | 0.27m / 0 |
| 移动起步/外推力 | 关闭；保留原有小初始扰动 |
| 域随机化/传感噪声 | 保留原v16温和配置 |
| 动作处理/奖励/电机 | 保持原接口、v16奖励、A_legacy轮端映射和原PD/速度环 |
| 默认训练 | 150轮，4环境×256 rollout，batch256，固定lr1e-4，entropy0.001 |
| 保存/评估 | 每50轮保存；结束后以64010–64014测试站立及全部低速起步 |

这是经过诊断选择的基础任务分布，**不代表保证收敛，不自动启动长期训练**。
它同时收窄了任务和扰动分布，不是一项单变量效果证明。25%独立站立回合用于避免只练起步而遗忘站立；
±0.1/±0.25提供较易任务，±0.5保留实际目标。所有概率从训练开始固定，不按奖励自动升速。
没有冻结腿、教师动作、手写平衡外环或额外限速器。

在仓库目录执行：

```bash
bash scripts/train_joint_startup.sh
```

脚本自动生成新版本名，拒绝覆盖已有检查点。明确指定输出名和种子：

```bash
VERSION=joint_startup_warm_s0_next SEED=0 bash scripts/train_joint_startup.sh
```

脚本后的参数传递给训练器，例如调整训练轮数。默认SOURCE为
`checkpoints/joint_tracking_pos_v16_model20261104/checkpoint`，不需要另加`--checkpoint`。
显式设置`FROM_SCRATCH=1`才会从头训练；该选项保留用于对照，不是当前推荐。
默认保留新版仿真模型、电机映射和奖励，训练日志、权重、评估分别落在logs、checkpoints、diagnostics的同名版本目录。
如需查看中途结果，先找到该版本的保存点，再运行：

```bash
conda run --no-capture-output -n wheelleg-train python scripts/eval_new_model_training.py \
  checkpoints/<版本名>/checkpoint_iter_50 \
  --output diagnostics/<版本名>/eval_50 \
  --launch-speeds .1 .25 .5 --seeds 64010 64011 64012 64013 64014
```

先要求站立和正反向低速均满足姿态及速度要求，再在至少两个训练种子上复现；随后单独评估±1、±2、变高度、转向、停车、换向与推力。
不能因6000轮完成或奖励转正直接回到全命令分布。最终自动评估为名义参数验收，不能替代域随机化或硬件验证。

已完成8轮真实CLI接口短测（2环境×128步，共2048个转移）及35个自动评估回合，确认从头初始化、
新版MJCF、采样、关闭推力、检查点契约和自动评估可运行。8轮模型没有学会平衡，这些评估只用于接口检查。
采样测试和续训CLI回归测试均通过，模型文件未改。
