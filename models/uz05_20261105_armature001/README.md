# UZ05：轮侧附加惯量0.001候选

当前默认XML：`uz05_rl.xml`。基于`../uz05_20261104/uz05_rl.xml`，只将左右轮轴joint的armature从0.01改为0.001kg·m²。compiler.meshdir改为引用原版本的网格，避免重复复制资源。其余质量、COM、惯量、轮径、腿部几何、阻尼、碰撞、求解器和XML执行器上限均保持。

此值为用户在无法准确取得改装减速箱惯量时指定的待标定候选，不是厂商公布值，也不是由整机重量计算出的实测结果。现有减速比268/17保留。计算依据、资料边界和验证见`../../docs/wheel_armature001_20261105.md`；哈希与参数来源见`model_change.json`。

原0.01版本及旧0.0001版本保留。历史权重必须显式选择训练时使用的XML，模型哈希不兼容时拒绝直接续训；本次未修改任何checkpoint契约。
